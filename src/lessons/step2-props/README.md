# 2단계 · props — 컴포넌트에 값 전달하기

부모가 자식에게 값을 건네는 통로가 **props**다. 두 걸음으로 나눠 배운다.

| 하위 | 배우는 것 | 폴더 |
|---|---|---|
| **2-1** | props 기초 (문제 → 하나 → 여러 개) + 🎯실습 | `step2-1-basics` |
| **2-2** | 더 넘겨보기 (함수·상태·객체 전달) | `step2-2-more` |

## 한눈에

`props` = 부모가 자식에게 건네는 **값** (함수의 인자와 같다).

```jsx
<HelloName name="김코딩" />          // 부모: 값을 건넴
function HelloName({ name }) { ... }  // 자식: {name}으로 받아 씀
```

- 부모 → 자식 **한 방향**, 자식은 **읽기만** 한다 (읽기 전용·불변).
- 값·객체·**함수**까지 무엇이든 넘길 수 있다. 부모의 **상태**를 내려주면 동적으로 바뀐다.
