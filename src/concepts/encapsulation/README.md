# 개념 · 캡슐화 (겉은 컴포넌트, 속은 감춰진다)

> 📂 파일
> - `MenuItem.jsx` — 아이콘+라벨+`Badge`를 합친 조립 컴포넌트 (조각의 조각)
>   - `Badge`는 공용 `src/components/Badge.jsx` (여러 개념에서 함께 씀)
> - `AppMenu.jsx` — MenuItem들 + `<hr>`(순수 HTML)의 조합
> - `index.jsx` — 개념 화면

`AppMenu`는 전부 `<컴포넌트 />`의 조합으로 보인다. 그런데 각 조각의 **속**은 다르다.

```jsx
<nav>
  <MenuItem icon="🏠" label="홈" />        {/* 조립 컴포넌트 (아이콘+라벨+뱃지) */}
  <MenuItem icon="🔔" label="알림" badge="3" />
  <hr />                                     {/* 그냥 HTML 통짜 */}
  <MenuItem icon="⚙️" label="설정" />
</nav>
```

아래 메뉴에는 같은 `MenuItem`이 **20개** 쓰인다. (정의는 하나, 사용은 여러 번)

## 초보에게 주는 의미

- 바깥에서는 복잡하든 단순하든 **똑같이 `<이름 />`** 으로 쓴다. (일관된 사용법)
- 쓰는 쪽은 내부 구현을 **몰라도** 된다 → **캡슐화**.
- `MenuItem` 속을 나중에 바꿔도 **쓰는 코드는 그대로**다.

→ **복잡한 UI를 단순한 조각의 조합으로 다룰 수 있다** — 이것이 컴포넌트 사고방식의 핵심이다.

## 🔎 확인해보기 — 한 컴포넌트를 고치면, 그걸 쓰는 전부가 바뀐다

정의는 각각 **한 파일**인데, 고치면 그걸 쓰는 곳이 **전부** 바뀐다.

1. **MenuItem 배경**: `MenuItem.jsx`의 `<div className="menu-item">`에 `style={{ background: '#fff7ed' }}` 추가 → **20개 항목** 전부 바뀜.
2. **Badge 기본색**: `Badge.jsx`의 기본값 `color = 'var(--red)'`를 `'#7c3aed'`로 바꿈 → **기본색을 쓰는 뱃지(알림·메시지)**가 전부 보라로. (할 일·뉴스는 각자 `color`를 넘겨서 그대로)

> 기본값 한 곳을 고치니 기본색 뱃지가 전부 바뀐다. 반대로 특정 뱃지만 바꾸려면 `color`를 넘긴다 — **재사용 + 커스터마이즈**를 동시에. 이게 props의 힘이다.

## 🤔 "순수 HTML도 CSS로 재사용되잖아?" — 이런 반박은?

절반은 맞다. **CSS는 '스타일(외형)'을 재사용**한다. (리액트에서도 스타일은 여전히 CSS로 재사용한다!)
하지만 재사용의 **층위**가 다르다.

| 무엇을 재사용? | 순수 HTML + CSS | 리액트 컴포넌트 |
|---|---|---|
| 스타일(외형) | ✅ class로 | ✅ (여전히 class로) |
| 구조(마크업) | ❌ 매번 복붙 | ✅ `<MenuItem />` 한 줄 |
| 인스턴스별 데이터 | ❌ 손으로 각각 | ✅ props로 주입 |
| 동작/상태 | ❌ JS 따로 복붙 | ✅ 컴포넌트에 내장 |

> **CSS는 껍데기(스타일)를, 컴포넌트는 알맹이(구조·데이터·동작)까지 공유한다.**
> 컴포넌트는 CSS를 대체하는 게 아니라, CSS가 **못 하는** 재사용을 더한다.

### 결정타 — "20개 항목 전부에 화살표 › 추가해줘"

스타일이 아니라 **구조(요소)** 를 바꾸는 요청이다.

```
순수 HTML:  20개 <div>마다 <span>›</span>를 20번 복붙 수정 (CSS는 요소를 못 만든다)

컴포넌트:   function MenuItem({ icon, label }) {
              return <div>{icon} {label} <span>›</span></div>  // ← 한 줄
            }
            → 20개 전부 반영
```

색(스타일)은 CSS로도 한 번에 바꿨지만, **화살표(구조)·항목별 라벨(데이터)·클릭(동작)** 은 CSS가 못 한다. 그래서 컴포넌트다.
