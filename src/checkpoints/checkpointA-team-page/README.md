> 📂 파일
> - `practice.jsx` — 내가 완성할 실습 파일 (TODO 있음)
> - `solution.jsx` — 정답 예시 (앱에서 "정답 보기"로 확인)

## 목표

1~2단계를 합친 **누적 실습**이다. 배운 것으로 작은 결과물 하나를 직접 만든다.

- 1단계: 컴포넌트 만들기
- 2단계: props로 값 넘기기 · 재사용

## 과제

1. `Member` 컴포넌트를 완성한다. props로 `emoji`, `name`, `role`을 받는다.
2. 팀원 **3명**을 서로 다른 값으로 렌더한다.
3. 같은 `Member`를 3번 재사용하는 것을 확인한다 — 정의는 하나, 사용은 여러 번.

막히면 앱에서 **👀 정답 보기**를 눌러 `solution.jsx` 결과와 비교해 보자.
정답은 하나가 아니다 — 이름·직업·이모지는 마음대로 바꿔도 된다.
