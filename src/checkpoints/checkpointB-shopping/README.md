## 목표

3·4·6단계(상태·입력·리스트)를 한꺼번에 쓰는 **누적 실습**이다.

- 3단계: 상태(useState) · 이벤트
- 4단계: controlled input
- 6단계: 배열 상태 · map · key · 추가/삭제

## 과제

1. 입력창을 **controlled**로 만든다. (`value`, `onChange`)
2. **추가** 버튼으로 `items` 배열에 새 항목을 넣는다. (`[...items, 새항목]`)
3. `items`를 **map**으로 목록으로 그린다. (`key` 필수)
4. 각 항목의 **✕**로 그 항목을 뺀다. (`filter`)
